# broken-english-public

Pages publiques de l'application **Broken English**, servies par GitHub Pages sur le domaine personnalisé **brokenenglish.app** (via `CNAME`).

| Page | Fichier | URL |
| --- | --- | --- |
| Landing page | `index.html` | https://brokenenglish.app/ |
| Politique de confidentialité | `privacy.html` | https://brokenenglish.app/privacy.html |

Dépôt volontairement séparé de celui de l'app : il ne contient que du HTML statique, sans dépendances externes.
Pour mettre à jour, éditer le fichier et pousser sur `main` — GitHub Pages redéploie tout seul.

**Fichiers système :**
- `CNAME` : configuration du domaine personnalisé
- `robots.txt` et `sitemap.xml` : optimisation pour les moteurs de recherche
